# Personal biodata portfolio

This is a dependency-free, static portfolio site: open `index.html` in a browser to preview it.

## Make it yours

1. In `script.js`, replace the values in the `profile` object. It controls the name, contact details, education, skills, career goal, and links.
2. Adjust or remove rows from the `bio` list if you do not want to share a particular detail publicly.
3. Add more entries to the `education`, `skills`, or `socials` lists as needed.

## Gradual next steps

- Add a profile photo and a downloadable résumé.
- Add a portfolio or achievements section when you have projects to share.
- Publish on GitHub Pages, Netlify, or Vercel.
